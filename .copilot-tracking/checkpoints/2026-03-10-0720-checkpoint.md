## Key Decisions

1. **Single package vs workspace members**: Used single `graphtor-core` package with `[lib]` + `[[bin]]` targets (ADR-0001). Plan.md showed single `src/` directory — workspace with separate members would add unnecessary nesting for Phase 1 scaffolding.
2. **thiserror 2.x**: Used latest major version. API is compatible with 1.x usage patterns.
3. **Clippy pedantic doc-markdown**: Product names (`GraphRAG`, `LanceDB`, `Kùzu`) must be wrapped in backticks in `//!` and `///` doc comments to satisfy `-D clippy::doc_markdown`.
