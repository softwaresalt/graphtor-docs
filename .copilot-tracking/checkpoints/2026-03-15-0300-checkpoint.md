## Key Decisions

1. **All result types in `result.rs`** — prevents circular imports between submodules
2. **`AcquisitionPlan.allowed_root`** — stores the security boundary so execute() can pass it to scan_local_source() without changing the execute() API further
3. **`execute(plan, dry_run: bool)`** — dry_run added as explicit parameter per T044 spec
4. **Shallow clone fallback** — when `file://` local transport rejects depth(1), retry without depth (test-infra compatibility)
5. **`build.rs` for advapi32** — libgit2-sys link pragma does not propagate to integration test binaries on Windows MSVC; must re-emit
6. **`&[PathBuf]` over `Vec<PathBuf>`** — clippy pedantic `needless_pass_by_value` requires slice references
7. **`validate_sources()` is infallible** — returns ValidationReport; single-pass error collection without early exit
