## Key Decisions

1. **`pub fn run()`** — must be `pub` (not `pub(crate)`) because integration tests in `tests/` are external crate users.
2. **`model: Option<&EmbeddingModel>`** — `None` skips embedding; allows tests to run without 80MB model download.
3. **`path_str` = source-relative** — `strip_prefix(allowed_root)` so chunk IDs (SHA-256 of content + path_str) are portable across checkout locations.
4. **`batch_size` clamped to 1** — `slice::chunks(0)` panics at runtime; guard added with `warn!`.
5. **Embeddings computed but not stored** — HNSW vector indexing is 009-F scope; this feature validates embeddings run but does not persist vectors.
