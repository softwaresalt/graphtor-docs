# Compacted Memory — Shipment 049-S (full Ship lifecycle)

This is the consolidated Ship-owned memory record for shipment `049-S`
("Fix MCP serve initialize-handshake regression / Copilot CLI OS error
232", covering feature `056-F`), now fully closed. Verbose originals are
preserved at `docs/archive/memory/2026-09-13/` (paths listed above);
Stage-owned memory for the same shipment (deliberation/remediation/review
cycles, filenames prefixed `stage-`/`049-s-stage-`, plus the single

touched by this compaction — Ship does not mutate another agent's memory
(Role Boundary, Continuity row).

## Timeline and Decisions

staging/preparation only — no shipment claim, no task implementation) ready

### Phase 3 — `049-S` implementation, dark-factory run (2026-09-12, PR #120)

Shipment `049-S` claimed; all 8 manifest tasks (`056.001-T`, `056.002-T`,
`056.003-T`, `056.019-T`–`056.023-T`) implemented on
`chore/fix-mcp-serve-initialize-handshake-regression`:

* Built `tools/mcp-probe`, a standalone exact-CLI differential-probe crate
  (`056.020-T`–`056.023-T`): bounded-transport duplex pump, `ChildGuard`
  RAII process teardown with fail-closed identity matching, wrapper/exact-
  CLI subcommands, evidence collection with redaction. A real deadlock bug
  (unconditional stderr-thread join on the timeout path) was found and
  fixed during red/green development.
* Built the reusable out-of-process `initialize`-handshake test driver
  (`tests/common/serve_driver.rs`, `tests/serve_handshake_driver_test.rs`,
  `056.002-T`) — the first automated harness able to literally exercise a
  real JSON-RPC `initialize` request/response cycle against the compiled
  binary (previously only a manual live-client checkpoint could do this).
* **Standard 9-persona review** (Constitution, Rust, Correctness,
  Maintainability, Concurrency, Architecture, Security, Scope Boundary
  Auditor, read-only Learnings Researcher): 6 P0/P1 findings, all fixed
  in-scope except one genuinely new-scope finding (`--allow-all-tools`
  prompt-only safety gate lacking technical enforcement) captured per
  P-021 C2 as stash `ECD56875` (high/feature, requires deliberation) —
  the only stash mutation Ship performed, per the C5 capture-only
  carve-out. Outcome: `READY_WITH_FOLLOWUPS`. The Learnings Researcher
  pass flagged 4 candidate new compound-learning topics (containment-
  reimplementation pattern, typed observability-seam pattern, backlogit
  auto-archive-on-`done` behavior, OS-error-232 root-cause signature) —
  deferred to post-merge; 2 of the 4 were captured during this closure
  (see Phase 6 below).
* **Adversarial multi-model review** (3 reviewers: `gpt-5.6-sol` anchor,
  `claude-haiku-4.5`, `claude-opus-4.8` substituting for an unavailable
  model): 0 HIGH-confidence consensus findings; 1 MEDIUM + 10 LOW, all
  fixed or acknowledged (one reviewer claim about Windows `rename`
  independently refuted and excluded; one finding reframed from security
  to portability). Report:
  `docs/closure/2026-09-13-fix-mcp-serve-initialize-handshake-regression-adversarial-review.md`.
* **Discovered backlogit 1.10.1 behavior**: a task's `done` transition
  immediately relocates its file `queue/` → `archive/`, independent of the

  `--commit {sha}` evidence writes to Step 6 post-merge safe-close, once
  the real merge SHA exists. Captured as compound learning during this
  closure (Phase 6).
* All quality gates green throughout (clippy pedantic, fmt, full test
  suite, `cargo audit` with the CI-exact allowlist) at every phase
  boundary.

### Phase 5 — Merge, shipment-closure tool-capability gap, and cascade recovery (2026-09-13)

PR #120 was subsequently merged (merge commit
`98f8fc63024095b0b8697545986646a564677917`, confirmed via
`gh pr view` + `git merge-base --is-ancestor`). Post-merge safe-close then
hit a genuine backlogit tool-capability gap: `backlogit move --status
shipped` / MCP `backlogit_move_item` is unconditionally refused
(`shipment_shipped_requires_envelope`) on the installed 1.10.1 build; only
the P-015-forbidden `backlogit shipment ship` cascade can reach `shipped`.
The operator explicitly authorized running the cascade as a one-time
policy exception; it succeeded, correctly archiving `049-S`
(`archived_status: shipped`, correct commit), but its recursive manifest
resolution cleared `parent_id: 056-F` from 25 out-of-manifest sibling
tasks (`056.004-T`–`056.018-T`, `056.024-T`–`056.033-T`) as a disclosed,
bounded side effect. `backlogit adopt` was evaluated and rejected as a
repair tool (unsafe non-gap-aware ID rewriting for 15/25, unconditional
`origin_feature` injection for all 25). The operator selected the
simplest recorded option: a direct, byte-exact, field-only restoration of
the missing `parent_id` line on all 25 records, followed by
`backlogit sync` — executed and verified byte-exact (only the tool-managed
`updated_at` differing) by the session that produced this closure
document. Full detail: `.backlogit/reconcile/049-S-halt-20260913T053721Z.md`
(now `status: resolved`).
