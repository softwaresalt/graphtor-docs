## Description

Refactor `PdfExtractBackend::parse` in `src/parse/pdf.rs` to remove the `LARGE_PDF_THRESHOLD` fast-path and switch Pass 2 (HeadingAwareOutput) from `pdf_extract::output_doc` (full traversal) to `pdf_extract::output_doc_page` in a page-by-page loop.

## Acceptance Criteria

- `LARGE_PDF_THRESHOLD` constant removed or dead-code-cleaned
- `PdfExtractBackend::parse` no longer branches on file size to skip heading-aware extraction
- Pass 2 uses `output_doc_page` in a bounded loop over all pages (mirroring Pass 1 histogram approach)
- `HeadingAwareOutput` state machine continues to accumulate heading context across page boundaries (already designed for this)
- All existing unit tests pass unchanged
- Quality gates pass (cargo check → clippy → fmt → test)
