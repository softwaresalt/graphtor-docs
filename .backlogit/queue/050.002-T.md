Add a NEW serve/status-scoped `serve_discovery` module that scans the `.graphtor/` root for `*.db` AND preserves the existing serve candidate inputs. The served set is a UNION of: (a) existing configured source TARGET db paths from `discover_db_files` (src/main.rs:244-255) — INCLUDING generation targets that do NOT exist on disk yet; (b) the explicit CLI `--db-path` / no-config candidate (src/main.rs:2408-2417); (c) workspace-contained `type: database` entries (merged by P1-T6 / 050.006-T); and (d) newly auto-discovered EXISTING `*.db` files in the `.graphtor/` root. Auto-discovered (d) entries MUST NEVER be fed back into `discover_db_files` / `split_plan_by_database` (the sync/write chokepoint) — they are force-classified read-only. Do NOT modify `discover_db_files` / `split_plan_by_database`. The zero-db ('no databases found to serve') exit fires ONLY when the FULL union is empty. Files: src/workspace/serve_discovery.rs (new), src/workspace/mod.rs (wire). Test-first.

<!-- BEGIN:acceptance-criteria -->
Three high-level verification scenarios (all substantive checks retained):

(a) union discovery / happy path — the served set is the canonical-path-deduped UNION of the existing source-derived/explicit `discover_db_files` candidates AND the new auto-discovered root `*.db` entries; a dropped `.db` in the `.graphtor/` root is discovered; the zero-db ('no databases found to serve') exit fires ONLY when the FULL union is empty.

(b) safety / containment — the root scan skips `*.lock`, index/tmp, `.graphtor/models`, generated artifacts, and non-`.db` files, and rejects `..` traversal, POSIX symlinks, and Windows junctions/reparse points that escape the canonical root; auto-discovered (root-scan) entries are NEVER passed to `discover_db_files` / `split_plan_by_database` / sync; `discover_db_files` / `split_plan_by_database` are untouched (characterization guard).

(c) compatibility / regression — a fresh source-backed workspace whose configured target db does NOT exist on disk yet still reaches serve (the missing target is in the union) instead of the 'no databases found' exit; an explicit `--db-path` / no-config candidate is honoured and served even when no `.graphtor/*.db` root-scan hit exists.
<!-- END:acceptance-criteria -->

<!-- BEGIN:implementation-notes -->
Preserve existing candidates (PR #88 review comments 3588875971 / 3588876019): today `serve` already includes every configured source target via `discover_db_files` (src/main.rs:244-255) EVEN when that target db is not yet created, and the no-config path honours an explicit `--db-path` (src/main.rs:2408-2417). The new root scan MUST be ADDITIVE to those inputs, not a replacement — otherwise a fresh generation workspace hits the new zero-db exit before it can create/sync its target, and an explicit `--db-path` target is dropped. Union assembly + canonical-path dedup live in `serve_discovery`; the `type: database` explicit entries (c) are merged by P1-T6 (050.006-T). Only the auto-discovered (d) subset is force-classified read-only and kept OUT of the sync helper; source-derived/explicit candidates keep their existing posture-resolution path (content-derived classification lands in P1-T2). Containment for the root scan: canonicalize the root and each candidate, normalize the Windows `\\?\` UNC prefix, assert the canonical candidate is prefixed by the canonical root. Root-scan served set = `*.db` by extension minus the locked skip-list. Expose a pure union+dedup helper for unit tests.
