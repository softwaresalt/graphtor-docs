Make the MCP config writer (generate_mcp_config / managed_server_value, src/workspace/mcp_config.rs:84-97) the shared foundation both install paths consume. It provides: (a) a binary-resolution LADDER - reference the pinned absolute .graphtor/bin/graphtor-docs (+ platform ext) when a managed binary exists, otherwise the bare graphtor-docs PATH command (no .exe; Windows resolves via PATHEXT); (b) a managed-entry PROVENANCE MARKER written into the server entry so uninstall (P2-T5b) can identify the graphtor-managed entry; (c) ATOMIC temp-file + rename writes with stable key ordering (Principle IX). This is the Phase-2 root. Files: src/workspace/mcp_config.rs (+ a shared atomic-write helper if extracted). Depends on Phase 1 (050-F). Test-first.

<!-- BEGIN:acceptance-criteria -->
resolution ladder unit-tested as a pure function - managed binary present -> pinned .graphtor/bin/graphtor-docs + platform ext; no managed binary -> bare graphtor-docs PATH command with NO .exe; every written managed server entry contains the managed-entry provenance marker; the write is atomic (temp-file + rename) with stable key ordering; a pre-existing .mcp.json with user-authored entries is preserved (only the managed entry is written/updated).
