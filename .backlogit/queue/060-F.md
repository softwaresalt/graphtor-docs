## Blocked upstream-dependency tracker (self-contained)
This is a reviewed, blocked-on-upstream tracking record. It is NOT local graphtor capability work and has no repo-executable plan; it exists so the dependent 054-S -> 053-S -> 052-S chain has a durable, reviewed backlog reference.

## Summary of the defect
backlogit 1.10.1 has no non-destructive, non-cascading primitive to transition a partial-feature, task-only shipment record to terminal "shipped". This blocks honest closure of 054-S (manifest [056.028-T], covering feature 056-F excluded per P-015) and P-001 eligibility of dependent shipments 053-S (deps [049-S,054-S]) and transitively 052-S. Direct "backlogit move/update <shipment> --status shipped" is refused by the compiled-in `shipment_shipped_requires_envelope` guard; the only alternative, `backlogit shipment ship` (ShipShipment), cascades upward to the covering feature then downward across all descendants, clearing parent_id on out-of-manifest siblings (observed on 25 siblings during 049-S).

## Target ownership (WHERE the fix belongs)
UPSTREAM backlogit product source -- the compiled-in `shipment_shipped_requires_envelope` guard and the `ShipShipment` descendant-walking scope resolution. NOT implementable in graphtor-docs: this repo contains only the graphtor-core / graphtor-docs Rust crates and consumes backlogit as an external prebuilt binary (C:\Tools\backlogit.exe). No local code owns the shipment state machine. Blocked-on-upstream; not a graphtor code change.

## Severity / priority
high -- gates the 053-S -> 052-S release chain until resolved.

## Acceptance criteria (for the UPSTREAM fix)
1. A shipment whose manifest is fully terminal (all manifest members archived/done) can reach "shipped" WITHOUT the descendant-walking cascade -- e.g. an envelope/close operation scoped strictly to manifest members.
2. MUST NOT requeue/detach or rewrite parent_id on any out-of-manifest sibling/descendant of a manifest task's covering feature (the P-015 protected set). Regression-verified against a 054-S/056-F-shaped fixture (task-only manifest, covering feature excluded, out-of-manifest siblings present).
3. Shipment status enum (queued->active->shipped|abandoned) respected; direct move/update behavior unchanged or replaced by a documented non-cascading close command.
4. After closure, dependent shipments whose dependency list includes the closed shipment become P-001-eligible.
5. backlogit release notes updated; workspace compound doc docs/compound/2026-05-07-backlogit-shipment-status-constraints.md refreshed to the new supported path once released.
