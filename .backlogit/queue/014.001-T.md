File: src/workspace/lock.rs:88\n\n`WorkspaceLock::acquire()` writes the lock file with `fs::write`, which is not atomic w.r.t. creation and can race with a concurrent `acquire()`. Two agents checking `path.exists()` simultaneously could both see `false` and proceed to write.\n\nFix: Use `OpenOptions::new().create_new(true).write(true).open(&path)` (equivalent to `O_CREAT|O_EXCL`). This atomically fails if the file already exists. Fall back to the stale-check path on `AlreadyExists` error.\n\nAlso add a unit test simulating the race condition with two rapid sequential acquires.
