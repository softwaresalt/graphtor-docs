<!-- BEGIN:description -->
Create the reusable open-stdin, real-process MCP initialize driver and the branch-appropriate regression proof selected after T0. The driver sends valid newline-delimited JSON-RPC and accepts only a negotiated initialize response as success. Repository-code branches commit an observed-red test that their curative task greens: H0a through 056.008-T's generated-entry fixture, H0b through a reachable Generation-lock fixture, H3 mode A through a framing-pinned fixture, and H1 through 056.005-T's deterministic loader seam plus runtime confirmation. Operational-only H0c and H3 mode B use bounded before/after actual-client transcripts instead of leaving an unsatisfiable Cargo test. Exit/stderr/timeout remain diagnostics, never the passing assertion.
<!-- END:description -->

<!-- BEGIN:implementation-notes -->
Keep stdin open; a closed stdin only exercises benign EOF. The reusable driver must own and clean up the exact child it spawns. Separate deterministic code tests from runtime evidence: H1 unit tests inject a blocking/failing loader rather than relying on a cold Hugging Face cache, while non-H1 integration tests prewarm/pin model state out of the path. H0b fixtures must classify a Generation target before lock acquisition is reachable. H0c external state repair and H3 mode-B client selection are verified by rerunning the same bounded actual-client probe before and after the change; no permanent red test is committed for an external-only change.
