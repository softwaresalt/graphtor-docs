The test references REPARSE_ATTR and never repeats the numeric literal 0x0000_0400, which occurs exactly once in the module (inside U2's REPARSE_ATTR definition). The assertion references REPARSE_ATTR -- it does NOT repeat the numeric literal 0x0000_0400 -- so g2's single-source invariant (the literal occurs exactly once, inside REPARSE_ATTR) is preserved. (g2) STRUCTURAL single-source proof (#[cfg(windows)]): a #[cfg(windows)] test drives the production Windows refusal branch through should_refuse_reparse so it cannot be a decorative unused helper, and the module contains exactly ONE occurrence of the numeric literal 0x0000_0400 (inside the REPARSE_ATTR definition) -- production and tests reference REPARSE_ATTR -- so no duplicated inline mask can exist.
