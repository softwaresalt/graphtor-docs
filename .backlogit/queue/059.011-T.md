Add colocated tests for the deterministic reparse-predicate DELTAS split out of U5 (059.005-T). Bounded to at most three test scenarios: (f) DETERMINISTIC normal-CI predicate unit test (REQUIRED, ALWAYS executes on Linux CI): test the pure, target-independent should_refuse_reparse(file_attributes: u32)->bool predicate (extracted in U2), which is the SINGLE SOURCE OF TRUTH and tests against a MODULE-PRIVATE literal bit constant const REPARSE_ATTR = 0x0000_0400 (the numeric value of FILE_ATTRIBUTE_REPARSE_POINT; not pub/pub(crate), referenced only inside the predicate), with FABRICATED attribute-bit inputs -- reparse bit (0x0000_0400) set -> refuse; clear -> allow; reparse bit combined with unrelated bits (FILE_ATTRIBUTE_READONLY/FILE_ATTRIBUTE_HIDDEN) -> still refuse. Because the predicate and its literal are target-independent, this test COMPILES AND RUNS ON LINUX CI with NO filesystem, NO privilege, NO reparse fixture, and NO windows-sys, so it executes deterministically on every normal-CI job and pins the broader fail-closed policy even when U10's delta (e) real fixture skips. (g1) WINDOWS-ONLY literal-equality assertion (REQUIRED, #[cfg(windows)]): assert the literal 0x0000_0400 equals windows_sys::Win32::Storage::FileSystem::FILE_ATTRIBUTE_REPARSE_POINT (via const_assert or a #[cfg(windows)] #[test]), proving the cross-platform literal used by the predicate can never drift from the real Win32 constant. (g2) STRUCTURAL single-source proof (#[cfg(windows)]): a #[cfg(windows)] test drives the production Windows refusal branch through should_refuse_reparse so it cannot be a decorative unused helper, and the module contains exactly ONE occurrence of the 0x0000_0400/REPARSE_ATTR literal (inside the predicate) so no duplicated inline mask can exist. This task depends on U2 (059.002-T), which extracts the predicate, and is therefore transitively feasibility/integration gated (U2 depends on U1/U6/U9).
