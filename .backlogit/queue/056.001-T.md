<!-- BEGIN:acceptance-criteria -->
- The newest target Copilot CLI is the branch-selection source of truth. Run a same-build contrast pair from one controlled foreign launch directory that is distinct from the canonical project root: a control entry omits `cwd`, and a treatment entry requests the canonical project root.
- The temporary transparent wrapper records two identities separately: its CLI-assigned argv/cwd/allowlisted environment immediately at process entry before any chdir or inner spawn, and the exact inner server spawn identity. It must not rewrite cwd/env/args except substituting the real serve executable, and it proxies the bidirectional initialize transaction byte-for-byte.
- When the inner server exits, the wrapper promptly closes the client-facing pipes and propagates the exit so the CLI can observe the real closed-pipe/232 signature. Record CLI/wrapper/server PIDs, stderr, exit, and the unmodified bidirectional initialize transcript under `logs/`.
- The probe runner owns the target CLI process and wrapper; the wrapper owns the inner serve child. Enforce a 30-second deadline, reap only the isolated job/process tree, verify no probe-created lock or child survives, and restore the original MCP config byte-for-byte on success, failure, and timeout. If ownership cannot be established, fail the probe.
- A direct server replay is secondary confirmation derived from the actual-client launch/framing transcript; it cannot select the causal branch. Keep a named stdin handle open and record exit versus still-alive status.
- Presence/absence of `.graphtor/*.lock` is recorded. H0b additionally requires a `ServeMode::Generation` target.
- Conclude a named H0 sub-cause, or explicit H0-ruled-out plus H1/H3 pointer, from correlated evidence.
- Record the exact target CLI MCP schema: `type` versus `transport`, `cwd` support, and env handling. The minimal managed contract emits only the evidenced stdio discriminator and `cwd`; env is diagnostic only.
- `cwd` is supported only when the control wrapper starts in the foreign directory and the treatment wrapper starts in the requested canonical root under otherwise identical conditions. If both start in the foreign directory or the treatment is rejected, route to H3-B.
- Link the selected downstream H0c, existing-install, or H3-B recipe; do not host those implementation or documentation widths in T0.
<!-- END:acceptance-criteria -->
