- The actual target Copilot CLI invocation is the source of truth for the failing baseline. - A named H0 sub-cause, or explicit H0-ruled-out plus H1/H3 pointer, is concluded from correlated evidence.
- Record the exact target CLI MCP schema: `type` versus `transport`, `cwd` support, and env handling. The minimal managed contract emits only the evidenced stdio discriminator and `cwd`; env is diagnostic only.
- The same bounded probe proves whether a known canonical `cwd` is honored and leaves the original config bytes unchanged afterward. A direct `Command::current_dir` spawn is not client evidence.
- Host the H0c workspace-state remediation recipe (056.010-T), manual reinstall fallback (056.009-T), and H3-B client compatibility recipe (056.011-T).

The probe must restore config in a finally-style cleanup path and stop only processes in its isolated process tree. A genuinely absent default sources.yaml is not a gate; malformed registry or missing explicit `--config` is.
