P1-RF3 (Source-variant compatibility pre-refactor 3 of 5). Refactor the irrefutable `let Source::Local(...)` bindings in the pipeline record builder and the SYNC cycle so `Database` sources are filtered/ignored by design (sync never runs against a served read-only db). Sites: `build_source_record` (src/pipeline/mod.rs ~L709), the sync-cycle source binding `sync_source_with_frozen_mtimes_and_ignored_root` (src/sync/mod.rs ~L227), `build_new_state` (src/sync/mod.rs ~L1059). Route through `Source::as_local()` / `is_ingestible()` (P1-RF1 / 050.010-T); while only `Local` exists behaviour is identical, so this task is independently green. NO new variant is added here (that is P1-T6). Files: src/pipeline/mod.rs, src/sync/mod.rs (2 files). Depends on 050.011-T (P1-RF2). Test-first.

<!-- BEGIN:implementation-notes -->
`build_source_record` (src/pipeline/mod.rs ~L709): derive id/url/kind via `as_local()`; a served db is not built into a `SourceRecord` on the ingestion path.
`sync_source_with_frozen_mtimes_and_ignored_root` (src/sync/mod.rs ~L227): gate the local path via `as_local()` to obtain `local.path`.
`build_new_state` (~L1059): replace the `let Source::Local(_) = source;` assertion with `is_ingestible()`-gated handling.
Because sync consumes per-source, these gates make `cmd_sync` skip `Database` entries BY DESIGN once the variant lands — no separate top-level filter is needed because every consumer is gated. The mixed local+database `sync` integration test that verifies this is added in 050.006-T (P1-T6). Pure structural refactor; gates P1-T6. Executed by Ship; Stage plans only.
