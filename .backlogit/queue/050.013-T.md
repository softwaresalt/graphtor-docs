P1-RF4 (Source-variant compatibility pre-refactor 4 of 5). Refactor EVERY irrefutable/non-exhaustive `Source::Local` consumer in src/main.rs (the v4-migration + sync/prewarm command surface) so they are variant-safe BEFORE the `type: database` variant lands — this is the largest external file, with NINE production consumers. Production sites: `source_id` (~L655), `changed_source_fields` (~L661), `guard_no_embed_before_v4_rebuild` epoch-mismatch match (~L1280), `collect_candidate_md_files` (~L1310), `collect_snapshot_candidates` match (~L1410), `freeze_v4_migration_input` match (~L1486), `run_incremental_sync` match (~L2070), `cmd_prewarm` match (~L3382), and `prewarm_sync_source` match (~L3435). Also route the ONE colocated `#[cfg(test)]` binding (~L4323, the persisted-v4-snapshot retry test) through `as_local()` so main.rs's own tests stay green. Route id-only sites through the existing `Source::id()` accessor and the rest through `Source::as_local()` (P1-RF1 / 050.010-T); while only `Local` exists behaviour is identical, so this task is independently green. Uniform mechanical accessor-routing in a single file/domain (<=3 test-scenario families). NO new variant is added here (that is P1-T6). Files: src/main.rs (1 file). Depends on 050.012-T (P1-RF3). Test-first.

<!-- BEGIN:implementation-notes -->
Uniform mechanical accessor-routing across ONE file/domain: each site replaces an irrefutable `let Source::Local(...)` or single-arm `match` with a centralized accessor call, so despite the site count this stays width-isolated (one skill: variant-safe refactor) with <=3 test-scenario families (the <5-functions heuristic targets distinct logic changes, not uniform mechanical refactors).
Id-only sites — `source_id` (~L655) and the six `... => local.id...` match arms (`guard_no_embed_before_v4_rebuild` ~L1280, `collect_snapshot_candidates` ~L1410, `freeze_v4_migration_input` ~L1486, `run_incremental_sync` ~L2070, `cmd_prewarm` ~L3382, `prewarm_sync_source` ~L3435) — delegate to the existing `Source::id()` accessor (its match is centralized in source.rs), so adding the variant only touches source.rs. Because src/main.rs is the BIN crate (a SEPARATE crate from the library), it reaches `Source::id()` and `Source::as_local()` as the now-public accessors from P1-RF1 (050.010-T), which declares `as_local()` `pub` and widens `id()` from `pub(crate)` to `pub`; without that widening these bin-crate call sites would not compile.
`changed_source_fields` (~L661): replace `let (Source::Local(current), Source::Local(persisted)) = (current, persisted);` with `as_local()` on both operands, returning an empty/defensive changed-field set when either is non-local — a served db is not part of the v4 generation snapshot.
`collect_candidate_md_files` (~L1310): replace `let Source::Local(local) = &planned.source;` with `as_local()` to read id/include/exclude for the scan; a served db is skipped from the v4 migration candidate scan by design.
Colocated test (~L4323, persisted-v4-snapshot retry): route `let Source::Local(local) = &persisted.sources[0].source;` through `as_local()`. The four `source: Source::Local(LocalSource { .. })` CONSTRUCTORS in main.rs tests (~L3672/L3729/L3894/L4027) are non-breaking and untouched.
While only `Local` exists behaviour is identical. This closes the LAST src/main.rs consumer; only the EXTERNAL integration tests (P1-RF5 / 050.014-T) remain before the additive variant in 050.006-T. Pure structural refactor; gates P1-T6. Executed by Ship; Stage plans only.
