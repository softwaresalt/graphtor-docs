File: src/lib.rs

pub use mcp::DocServer in lib.rs couples the library crate's public API to the rmcp transport layer. DocServer is a binary concern — it is only needed by the binary entry point (src/main.rs) and should not be part of the library's public surface.

Required change:
- Remove `pub use mcp::DocServer;` from src/lib.rs
- Update src/main.rs to import DocServer directly: `use graphtor_docs::mcp::DocServer;` or via `crate::mcp::DocServer` if main.rs is the binary entry point that links the library
- Verify no external consumers (tests, benchmarks) depend on the lib.rs re-export

This enforces the library/binary boundary and prevents downstream crates from accidentally depending on the transport layer via the library API.
