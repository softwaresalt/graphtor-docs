Consume the engine-enforced read-only open primitive proven in P1-T0 (050.009-T) and apply the SERVE-side hardening for every ReadOnly-classified db (auto-discovered AND explicit workspace-contained entries from P1-T6): (1) keep v4 pre-sync gate parity — evaluate needs_v4_migration on the read-only store with NO write transaction, preserving the refusal message (open_serve_databases:2363); and (2) harden the RO open — disable loadable extensions, disallow ATTACH, and constrain to the single file — identically for ALL ReadOnly entries. The engine/filesystem-level no-write PROOF itself is owned by P1-T0 (050.009-T); this task does NOT re-prove it — it builds the v4 gate + hardening on top of that proven primitive. If P1-T0's feasibility proof fails, this task and shipment 045-S are already BLOCKED upstream (see P1-T0). Sequence AFTER P1-T3 (050.001-T) and P1-T6 (050.006-T); transitively gated by P1-T0 via the P1-T1 dependency. Test-first.

<!-- BEGIN:acceptance-criteria -->
Three high-level verification scenarios (all substantive checks retained):

(a) v4 gate parity — a pre-v4 (v3) discovered db is refused with the 'run sync' message (refusal exit); a v4 db is served; the v4 gate (needs_v4_migration) is evaluated on the read-only store with NO write transaction, preserving the refusal message (open_serve_databases:2363).

(b) ATTACH/extension hardening (auto-discovered) — a crafted auto-discovered read-only db attempting ATTACH or a loadable-extension load is refused/inert, with the RO open constrained to the single file.

(c) ATTACH/extension/single-file hardening (explicit entry) — an explicit workspace-contained read-only entry (from P1-T6) attempting ATTACH or a loadable-extension load is refused/inert, with identical single-file hardening applied to ALL ReadOnly entries.

Implementation footprint: < 3 implementation files (src/db/store.rs, src/main.rs) and ONE atomic milestone — v4 gate parity on the read-only store plus ATTACH/extension/single-file hardening applied uniformly to every ReadOnly entry, built on the P1-T0 read-only primitive.
