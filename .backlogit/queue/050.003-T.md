Establish an ENGINE/FILESYSTEM-level read-only open for every ReadOnly-classified db (auto-discovered AND explicit workspace-contained entries from P1-T6), plus automated no-write verification, and keep v4 pre-sync gate parity. The read-only open MUST use a backend/open mode that cannot create or mutate the db or its WAL/SHM/journal/lock sidecars (SQLite immutable=1/mode=ro URI or an equivalent SQLITE_OPEN_READONLY connection). Cozo's public SQLite backend exposes NO read-only connection flag and ignores the options string (src/db/store.rs:107-110,384), so the FIRST test-first step confirms engine-level read-only feasibility for the Cozo SQLite backend; if it cannot be guaranteed, the ReadOnly serve path FAILS CLOSED (refuse to serve that db with a clear error) rather than opening a write-capable handle and claiming INV-1 on the DataStore mutate-guard alone. Evaluate needs_v4_migration on the read-only store (no write transaction), preserving the refusal message (open_serve_databases:2363), and harden the RO open (disable loadable extensions, disallow ATTACH, constrain to the single file). Sequence AFTER P1-T3; also depends on P1-T6. Test-first.

<!-- BEGIN:acceptance-criteria -->
engine/filesystem no-write proof: capture the served .db (size, mtime, content hash) and assert NO creation or mutation of `-wal`/`-shm`/`-journal`/lock sidecars before AND after a full serve+query+search+semantic read cycle (hash and mtime unchanged); an attempted write/mutation against the read-only store is rejected at the ENGINE boundary (not merely the DataStore guard); if engine-level read-only cannot be guaranteed for the Cozo SQLite backend, the ReadOnly serve path fails closed with a clear error (never a silent INV-1 claim); pre-v4 discovered db -> refusal exit + 'run sync' message; v4 db -> served; a crafted auto-discovered db attempting ATTACH/extension-load -> refused/inert; an explicit workspace-contained read-only entry attempting ATTACH/extension-load -> refused/inert (same hardening for all ReadOnly entries).
<!-- END:acceptance-criteria -->
