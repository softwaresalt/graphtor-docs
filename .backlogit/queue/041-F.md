When an existing `.db` is detected under `.graphtor/data/` but no sources config
exists, auto-generate a local stub file with `sources: []` so that `serve` and all
other commands skip workspace auto-discovery and do not mutate the imported database.

## Acceptance Criteria

- `serve` on a workspace with an imported DB and no sources config does NOT ingest local markdown.
- A `sources.yaml` with `sources: []` is written to `.graphtor/config/`.
- `status --db-path` continues to work unchanged.
- Unit and integration tests cover the stub generation path.
