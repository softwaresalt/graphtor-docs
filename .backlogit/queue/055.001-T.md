Replace the relative_candidates Vec + single batch filter_files call with a streaming boolean using a SHARED reusable matcher (the same compiled include/exclude matcher filter_files uses) - do NOT call filter_files per file (that recompiles glob sets per entry and emits a per-file 'all files excluded' warning). If a shared predicate is not exposed by graphtor_core::acquire, extract/expose one so the classifier and filter_files share a single matcher (no forked glob logic). A traversal short-circuit (return true on first eligible file) is REJECTED: it would skip later walk errors and escalate a partially-unreadable read-only source to the read-WRITE Generation posture.
