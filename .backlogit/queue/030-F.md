Add `--json` global flag to every CLI command that outputs results in JSON-RPC 2.0 format (matching MCP server response structure) so agents can consume CLI output identically to MCP tool responses. Add a `graphtor-docs manifest` command that emits a JSON-RPC 2.0 tool manifest listing all CLI commands with names, descriptions, and parameter schemas — mirroring what the MCP server returns via `tools/list` on initialization. This enables CLI-first agent workflows without requiring the MCP STDIO server and ensures parity between CLI and MCP surfaces.
