Create the bounded, feature-gated, non-shipping transparent proxy and process harness used by the isolated evidence run (056.021-T). It performs full-duplex byte forwarding between the actual Copilot CLI and the inner MCP server without rewriting protocol bytes, and it owns the deadline plus all-outcome descendant teardown. It must not synthesize the closed-pipe symptom, leak a process between contrast legs, or rely on any owner-only build-artifact trust boundary. It builds with the standard Cargo target directory; the built binary is a normal, ephemeral build-cache artifact and never an evidence trust boundary. 056.021-T owns the isolated workspace, temporary config generation, and evidence lifecycle; 056.001-T owns the approved real-CLI run and branch ordering.
