<!-- BEGIN:description -->
Build the bounded, feature-gated, non-shipping transparent MCP byte proxy used by the isolated evidence run (056.021-T). It performs full-duplex byte forwarding between the actual Copilot CLI and the inner MCP server without rewriting protocol bytes, propagates half-closes, drains stderr under a bound, and signals timeouts. It exposes a read-only byte-observer seam so 056.021-T can capture raw transactions in memory without the proxy itself owning evidence, config, or process teardown. Process spawning, PID plus process-start-time identity, and teardown belong to 056.022-T; the isolated workspace, temporary config, and evidence lifecycle belong to 056.021-T; the approved real-CLI run and branch ordering belong to 056.001-T.
