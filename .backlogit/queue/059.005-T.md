Add colocated tests covering only the DELTAS that U3/U4 do not already assert (reference, do not re-implement, the U3/U4 cases): (a) the full sidecar-type matrix (-wal/-shm/-journal) fail-closed refusal on both open paths; (b) the platform fail-closed signal is asserted correctly per platform (Unix O_NOFOLLOW -> ELOOP open failure; Windows reparse open -> explicit FILE_ATTRIBUTE_REPARSE_POINT refusal); (c) reuse the try_symlink_file unprivileged-skip pattern and add a Windows junction variant so the Windows refusal path executes on unprivileged CI where possible; (d) validate the Windows retained handle (FILE_READ_ATTRIBUTES|FILE_WRITE_ATTRIBUTES, full share mode) does NOT block the engine's own db/WAL open -- scoped to that single assertion (Option A retained-handle vs the documented Option C identity-verified re-open fallback decision; record the outcome in the PR); (e) broader-fail-closed-policy regression (Windows): create a legitimate NON-redirecting reparse file whose reparse tag is NOT a name surrogate (a non-name-surrogate reparse point creatable without the symlink privilege where feasible) and assert the guarded open_no_follow path REFUSES it, proving the explicitly broader fail-closed policy adopted in U2 rather than a narrow name-surrogate-only check, so the intentional Windows/Unix breadth asymmetry is pinned by a test rather than left implicit. Skip GRACEFULLY (skip, not fail) when the test setup lacks the required privilege/support to create such a reparse file on unprivileged CI; in that case the doc-comment's accepted-breadth statement stands as the recorded behavior. Report executed-vs-skipped. (f) DETERMINISTIC normal-CI predicate unit test (REQUIRED, ALWAYS executes on Linux CI): test the pure, target-independent should_refuse_reparse(file_attributes: u32)->bool predicate (extracted in U2), which is the SINGLE SOURCE OF TRUTH and tests against a MODULE-PRIVATE literal bit constant const REPARSE_ATTR = 0x0000_0400 (the numeric value of FILE_ATTRIBUTE_REPARSE_POINT; not pub/pub(crate), referenced only inside the predicate), with FABRICATED attribute-bit inputs — reparse bit (0x0000_0400) set -> refuse; clear -> allow; reparse bit combined with unrelated bits (FILE_ATTRIBUTE_READONLY/FILE_ATTRIBUTE_HIDDEN) -> still refuse. Because the predicate and its literal are target-independent, this test COMPILES AND RUNS ON LINUX CI with NO filesystem, NO privilege, NO reparse fixture, and NO windows-sys, so it executes deterministically on every normal-CI job and pins the broader fail-closed policy even when the delta (e) real fixture skips; delta (e) thereby becomes OPTIONAL integration coverage layered on top, with explicit executed/skipped reporting. (g) WINDOWS-ONLY literal-equality assertion (REQUIRED, #[cfg(windows)]): assert the literal 0x0000_0400 equals windows_sys::Win32::Storage::FileSystem::FILE_ATTRIBUTE_REPARSE_POINT (via const_assert or a #[cfg(windows)] #[test]), proving the cross-platform literal used by the predicate can never drift from the real Win32 constant, AND STRUCTURALLY PROVING the production Windows refusal branch calls should_refuse_reparse: a #[cfg(windows)] test drives the production branch through the predicate so it cannot be a decorative unused helper, and the module contains exactly ONE occurrence of the 0x0000_0400/REPARSE_ATTR literal (inside the predicate) so no duplicated inline mask can exist. Reference (do not re-implement) U6 (059.006-T) intermediate-directory swap coverage; this task depends on U6. Consistent with docs/exec-plans/2026-08-24-store-toctou-nofollow-handle-plan.md U5 deltas (e), (f), and (g).
