Three high-level verification scenarios (all substantive checks retained):

(a) posture gating happy-path / mixed — a consumption db yields no rw store, no ensure_schema write, no write lock, and no sync spawn; a MIXED workspace (real-source + dropped db) gives the source-backed db rw+sync while the co-resident dropped db stays read-only and RO reads still work; mixed valid+stale sources targeting DIFFERENT dbs route ONLY the Generation db's source group to spawn_background_sync (the stale-source db is never re-split or synced).

(b) fail-safe / empty workspace — an empty .graphtor/ exits gracefully with 'no databases found to serve' (no graph.db write-fallback; the unreachable! at ~2490 replaced with a handled error).

(c) observability / edge — a tested positive startup log line reports the resolved per-db posture (ReadOnly/Generation) and the discovered-db count.
