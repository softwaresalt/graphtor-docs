SELECTED 2026-08-29 (`selection:selected`). Proven defect: an unhandled pre-`initialize` `server/discover` request is fatal. Live actual-client evidence identifies it as the first non-ping request (`id: 0`); rmcp 1.5 admits only ping in its pre-initialize loop, returns `ServerInitializeError::ExpectedInitializeRequest`, `cmd_serve` exits 2, and the client pipe closes. The remedy is only a private binary-owned transport interposer between `rmcp::transport::stdio()` and `rmcp::serve_server` that handles that one pre-initialize method, keeps the connection alive, then requires normal `initialize` and normal tools. It is the sole member of `052-S`, which now runs after `049-S`, the PHASE 1.5 unit (`056.028-T`), and the PHASE 1.6 declared-MSRV unit `053-S` (`056.029-T`). `056.011-T` no longer adjudicates the declared MSRV: the PR #108 review established that Cargo 1.75 predates edition 2024 (stable from Rust/Cargo 1.85) and therefore cannot parse the resolved edition-2024 `rmcp 1.5.0` manifest, so the former hard-coded `cargo +1.75.0` entry gate was a deterministic failure rather than a measurement. `056.029-T` resolves that mismatch first, and `056.011-T` validates only against the RESOLVED declared `rust-version` it leaves behind. Exact-Copilot before/after evidence, not the draft alone, must prove the response shape; T4 (`056.004-T`) alone owns restored-production acceptance.
