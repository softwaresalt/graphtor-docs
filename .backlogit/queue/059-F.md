updated_at: 2026-08-25T06:19:27.4570856Z

Eliminate two sibling check-then-use TOCTOU symlink/reparse swap vulnerabilities on the read-only permission mutation paths in src/db/store.rs by binding every permission operation to an identity-bound, no-follow file handle instead of re-resolving paths. Covers BOTH EngineReadonlyGuard lock/acquisition-rollback/Drop restore (main db index 0 + all sidecars) and clear_stale_readonly_lock write-mode sidecar permission probe/clear. Fail-closed on any link/reparse/unobtainable handle; NO path-based chmod fallback. Preserves exact-permission restoration and sidecar-content invariants. Consumes stash E86A6E56 (clear_stale_readonly_lock, high) and 5905CDEE (EngineReadonlyGuard, medium).

<!-- BEGIN:dod -->
- New test-first scenarios for main-db post-lock swap resistance, sidecar swap-at-clear refusal, and already-read-only clear all pass.
- All existing store::tests (exact-mode, byte-identical, non-empty-sidecar preservation, dangling-symlink refusal, stale-lock self-heal) pass unchanged.
- No path-based set_permissions/set_readonly remains on guarded/candidate entries in lock/Drop/clear_stale_readonly_lock.
- cargo build, clippy::pedantic -D warnings, cargo test, cargo audit all green; no new duplicate crate copy (cargo tree -d).
- Windows handle-mode decision (Option A retained-handle vs Option C identity-verified re-open) recorded in the release PR with test evidence.
<!-- END:dod -->

<!-- BEGIN:goals -->
- Open each guarded entry (main db index 0 + -wal/-shm/-journal sidecars) once with no-follow semantics and retain the File handle for the DataStore lifetime.
- Drive every permission op (capture, apply, acquisition rollback, Drop restore; write-mode probe+clear) through the retained handle.
- Remove the per-sidecar is_reparse_point re-check (superseded by no-follow open + explicit Windows reparse-attribute refusal).
- Guarantee cross-platform fail-closed behavior: Unix O_NOFOLLOW (ELOOP) and Windows FILE_FLAG_OPEN_REPARSE_POINT + explicit FILE_ATTRIBUTE_REPARSE_POINT post-open refusal.
- Preserve #![forbid(unsafe_code)], Rust 1.75 MSRV, and clippy::pedantic -D warnings.
