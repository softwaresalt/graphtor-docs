`upgrade()` of a consumption (minimal, no-bin) install treats missing `bin/`/subdirs as a no-op success rather than an error; a full install upgrade replaces the copied binary as today. Idempotent across both footprints. Files: src/workspace/upgrade.rs (+ src/main.rs cmd_upgrade if wiring is needed). Depends on P2-T1 (minimal install) + P2-T2b (full scaffold). Test-first.
