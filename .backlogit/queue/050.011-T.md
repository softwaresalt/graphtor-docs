P1-RF2 (Source-variant compatibility pre-refactor 2 of 5). Refactor the irrefutable `let Source::Local(...)` bindings on the ACQUISITION path AND filter the acquisition plan loop so `Database` sources are ignored by design (acquisition never ingests a served read-only db). Sites: the acquisition PLAN LOOP (`plan`, src/acquire/plan.rs ~L47-55 — the loop iterates `config.sources` and calls `resolve_source_dir` for EVERY source, so it MUST filter on `as_local()` BEFORE `resolve_source_dir`), `validate_sources` (src/acquire/plan.rs ~L90), `resolve_source_dir` (src/acquire/plan.rs ~L135), `execute_scan_local` (src/acquire/mod.rs ~L143). Route through `Source::as_local()` (added in P1-RF1 / 050.010-T); while only `Local` exists behaviour is identical, so this task is independently green. NO new variant is added here (that is P1-T6). Files: src/acquire/plan.rs, src/acquire/mod.rs (2 files). Depends on 050.010-T (P1-RF1). Test-first.

<!-- BEGIN:implementation-notes -->
`plan` plan loop (src/acquire/plan.rs ~L47-55): the loop currently calls `resolve_source_dir` for EVERY configured source unconditionally, so once P1-T6 adds the variant a mixed local/database config would FAIL planning (`resolve_source_dir` fail-closes on a non-local source) instead of ignoring the read-only entry (PR #88 thread PRRT_kwDORiB5E86RNyUU). Filter the loop with `if source.as_local().is_none() { continue; }` (or an `as_local()` `filter_map`) BEFORE `resolve_source_dir` so a `Database` source is skipped and never planned; while only `Local` exists every source passes (identical plan). Add a mixed local+database planning test asserting only the local source is planned once the variant lands.
`validate_sources` (src/acquire/plan.rs ~L90): replace `let crate::config::Source::Local(local) = source;` with `let Some(local) = source.as_local() else { continue; };` — a served db has no ingestion path/globs/formats to validate; count semantics are unchanged for local-only configs.
`resolve_source_dir` (~L135): gate on `as_local()`; it resolves an INGESTION target dir, which a served db does not have — fail-closed (return a `GraphtorError::Config`) if a non-local reaches it, since the planner filters `Database` out upstream by design.
`execute_scan_local` (src/acquire/mod.rs ~L143): gate the local scan behind `as_local()`.
These make acquisition filter/ignore `Database` entries automatically once the variant lands (050.006-T): the plan loop skips them, `resolve_source_dir` fail-closes as defence-in-depth, and validation/scan bypass them. Pure structural refactor; gates P1-T6. Executed by Ship; Stage plans only.
<!-- END:implementation-notes -->
