Research and implement guardrails to prevent direct-to-main pushes by agents. Incident: commits cbbfb81 and 3fd285a were pushed directly to main bypassing branch protection after a PR merge. Research scope: (1) git pre-push hooks that block pushes to main locally, (2) GitHub branch protection hardening (require PR, disable admin bypass for agents), (3) agent-level instruction/checklist enforcement in copilot-instructions.md, (4) CI workflow to detect and alert on direct main commits. Deliverable: a recommendation with the lowest-friction approach that works for both human and agent contributors, plus implementation.
