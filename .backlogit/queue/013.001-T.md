File: src/mcp/server.rs (and src/error/)

Currently all GraphtorError variants map to internal_error in the MCP error response. PathViolationError and ChunkIntegrityError represent invalid client input and should map to invalid_params instead.

Suggested implementation:
- Add a GraphtorError::to_mcp_error() method in src/error/ that returns the appropriate rmcp ErrorCode variant
- PathViolationError → ErrorCode::InvalidParams
- ChunkIntegrityError → ErrorCode::InvalidParams
- All other variants remain ErrorCode::InternalError
- Update src/mcp/server.rs tool handlers to call to_mcp_error() instead of hardcoding internal_error

This change improves MCP protocol compliance and lets AI clients distinguish recoverable input errors from genuine server faults.
