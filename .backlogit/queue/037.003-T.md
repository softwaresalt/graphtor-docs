Extend the prewarm handler to emit a single JSONL telemetry record to stdout on sync completion. The record follows backlogit's telemetry ingest format with `event_type`, `timestamp`, and a typed `payload` containing all `SyncMetrics` fields plus `sources_count`. Add `--quiet` flag to suppress stderr progress while preserving stdout telemetry.

## Acceptance Criteria

- stdout contains exactly one JSON line on successful `graphtor prewarm` completion
- JSON record validates against schema: `event_type`, `timestamp` (ISO-8601), `payload.files_total`, `payload.files_synced`, `payload.chunks_created`, `payload.duration_ms`, `payload.sources_count`
- `--quiet` flag suppresses stderr progress lines but preserves stdout JSONL
- Unit test parses captured stdout as JSON and validates all required fields
- `cargo clippy --all-targets -- -D warnings -D clippy::pedantic` passes
