Create docs/configuration.md.\n\nFull sources.yaml schema reference for all three source types:\n- GitSource: id, url, branch (default: main), include, exclude, formats (default: [\"md\",\"pdf\",\"docx\"])\n- LocalSource: id, path, include, exclude, formats\n- UrlSource: id, url, max_depth (default: 3), max_pages (default: 100), domain_lock (default: true), rate_limit_ms (default: 500), include, exclude, formats\n\nFormats allow-list semantics: empty = all supported extensions; non-empty = strict allow-list. Accepted values: md, pdf, docx.\n\nValidation rules: duplicate IDs, empty required fields, unknown format values.\n\nAnnotated example with all three source types.\n\nConfig path precedence: --config flag → env var → .graphtor/config/sources.yaml (relative to cwd).\n\nVerification: validate annotated example parses without error via SourceConfig::parse.\n\nPlan reference: Unit 3 in docs/archive/plans/2026-08-24-pre-august-compaction/2026-05-04-comprehensive-docs-plan.md
