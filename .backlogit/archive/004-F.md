Candle framework integration (candle-core, candle-transformers) for running all-MiniLM-L6-v2 (~80MB) natively in Rust. Produces 384-dimensional dense vectors entirely in-process with zero network overhead. Includes tokenization via tokenizers crate, mean-pooling, batch processing, and automatic model weight downloading via hf-hub.
