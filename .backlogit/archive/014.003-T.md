File: src/workspace/upgrade.rs:48\n\n`upgrade()` skips copying when source and destination file sizes match. File size is not a reliable equality check for binaries (different content can have the same size).\n\nFix: Compare file modification timestamps (mtime) or compute SHA-256 hashes for a reliable equality check. Prefer mtime comparison as it's fast and sufficient for the upgrade use case (same binary → same mtime from the build).
