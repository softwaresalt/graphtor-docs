Create `src/cli/prewarm.rs` and add the `Prewarm` variant to the clap `Commands` enum. The handler loads config, iterates sources, calls `sync_source` with a progress closure writing per-file progress lines to stderr with percentages, and prints a summary on completion.

## Acceptance Criteria

- `graphtor prewarm` executes, syncs all configured sources, and exits with code 0
- stderr contains file-level progress lines in format: `[syncing] source_id: file_name (idx/total) [pct%]`
- No output written to stdout during progress phase
- Integration test verifies prewarm runs against fixture directory and produces progress output
- `cargo clippy --all-targets -- -D warnings -D clippy::pedantic` passes
