Add four new formatting functions to `src/mcp/format.rs` following the existing `format_search_results` pattern:

1. `format_sources_list(&[SourceRecord]) -> String` — markdown table of sources (source_id, name, kind, url, synced_at). Returns "No sources indexed." when empty.
2. `format_chunk_detail(&ChunkRecord) -> String` — full chunk display with all metadata (chunk_id, source_id, path, position, heading_hierarchy, content).
3. `format_document_chunks(&[ChunkRecord]) -> String` — ordered chunk listing for a document. Truncate content to first 200 chars per chunk in listing mode to manage LLM context.
4. `format_status(&DbStatus) -> String` — health/stats markdown showing relation counts and schema version.

Tests (test-first):
- format_sources_list empty → "No sources indexed."
- format_sources_list with data → contains source_id, name, kind
- format_chunk_detail includes chunk_id, path, headings, content
- format_document_chunks preserves chunk ordering
- format_status shows relation counts
