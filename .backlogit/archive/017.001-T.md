Add two new DB-layer functions to support the MCP tool expansion:

1. `list_chunks_by_path(store, path) -> Vec<ChunkRecord>` in `src/db/chunks.rs` — returns all chunks matching a given relative document path, ordered by position. Reuse the exact column projection from `list_chunks_for_source` to maintain alignment with `row_to_chunk` (see compound learning: cozo-query-columns-must-match-struct).

2. `DbStatus` struct and `get_status(&self) -> Result<DbStatus, GraphtorError>` method on `DataStore` in `src/db/store.rs` — returns counts for each relation (doc_sources, doc_chunks, doc_edges, doc_code, doc_vectors) and the schema version. Derive `Debug, Clone, PartialEq, Serialize` on `DbStatus`.

Re-export new items from `src/db/mod.rs`.

Tests (test-first):
- list_chunks_by_path returns ordered chunks for a known path
- list_chunks_by_path returns empty vec for unknown path
- get_status returns correct counts after upserts
- get_status returns zeros for empty store
