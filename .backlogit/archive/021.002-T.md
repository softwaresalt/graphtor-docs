Add a `formats` field to `GitSource`, `LocalSource`, and `UrlSource` in `src/config/source.rs`. The field declares which document formats the source contains. When omitted, it defaults to `["md"]` for backward compatibility. Accepted values: `md`, `pdf`, `docx`.

<!-- BEGIN:acceptance-criteria -->
1. `formats: Vec<String>` field added to GitSource, LocalSource, and UrlSource
2. Serde default function returns `vec!["md".to_string()]` when field is omitted
3. Existing YAML without `formats` deserializes correctly (backward compat)
4. New YAML with `formats: ["md", "pdf", "docx"]` deserializes correctly
5. Unit tests in `src/config/source.rs::tests` cover both cases
6. All existing config_test.rs tests pass unchanged
<!-- END:acceptance-criteria -->
