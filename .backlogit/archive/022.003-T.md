Implement `HeadingAwareOutput` struct implementing `pdf_extract::OutputDev`. Core heading-detection engine that, given a known `body_font_size`, detects heading boundaries via font-size thresholds.\n\nBehavior:\n1. Accumulates text character-by-character in `output_character()`\n2. Tracks dominant font size per line\n3. Detects headings: H1 >= 1.6x body, H2 >= 1.3x body, body < 1.3x\n4. At heading boundaries: flushes current section, starts new section\n5. At `end_page()`: respects page boundaries as potential section breaks\n\nOutput: `Vec<PdfSection>` where each section has heading (Option<String>), heading_level (u8), content (String), page_start (usize).\n\nCompute `transformed_font_size` using geometric mean formula from PlainTextOutput.\n\nFiles: `src/parse/pdf.rs`\n\nTests:\n- Large font followed by small font produces heading + body\n- Multiple heading levels (H1 vs H2) detected correctly\n- Document intro (no heading) produces section with heading: None\n- Long section split at MAX_CHUNK_CHARS\n- Empty pages produce no spurious sections\n\nPlan: docs/exec-plans/2026-05-03-streaming-pdf-heading-aware-plan.md (Unit 3)
