Add integration tests verifying the complete new MCP tool surface works end-to-end. Create `tests/integration/mcp_tools_expansion.rs` (or extend existing MCP integration test file if one exists).

Test scenarios:
1. Full lifecycle: register source via upsert_source → upsert chunks → call list_sources → verify source appears in output
2. get_chunk_by_id: upsert a chunk, retrieve it by ID, verify content matches
3. get_document: upsert multiple chunks with same path, call get_document, verify all chunks returned in position order
4. get_document with source_id filter: upsert chunks from two sources at same path, verify filter works
5. get_status: after upserts, verify counts reflect the inserted data
6. Tool discovery: verify tools/list includes all 7 expected tools

All tests use in-memory DataStore with known test data. Follow existing integration test patterns in tests/integration/.
