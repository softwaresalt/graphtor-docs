File: src/mcp/format.rs

The format.rs module currently lives under src/mcp/ but contains pure formatting functions for SearchResult and TraversalResult types with no MCP-protocol-specific logic. If these types are used or could be used outside MCP contexts (e.g., CLI status output, future HTTP API), placing the module at src/format.rs improves discoverability and reusability.

Investigation steps:
1. Confirm the formatted types (SearchResult, TraversalResult) are defined in a shared location (not inside src/mcp/)
2. Check whether any non-MCP code already imports from this module or would benefit from doing so
3. If yes: move to src/format.rs, update all use paths, add module re-export or direct import in lib.rs
4. If no current non-MCP consumers exist: evaluate whether the types are likely to be shared in future features (010-F status command output is a candidate)

Priority is low — this is cosmetic/organizational. Document the decision either way with a brief comment or as a finding in the 013-F feature notes.
