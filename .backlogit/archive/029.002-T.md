Modify the `graphtor-docs serve` command to detect stale content at startup (compare stored commit hashes / mtimes against current state) and run an incremental sync automatically. Sync should be non-blocking: the MCP server starts accepting connections immediately while sync runs in a background tokio task. Add a sync_status field to `get_status` tool output so agents know when sync completes.
