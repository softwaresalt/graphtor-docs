title: Add global --json flag to CLI and wire through command dispatch
updated_at: 2026-05-06T12:24:31.8605422-07:00
---

Add a global `--json` flag to the `Cli` struct in `src/cli/mod.rs`. Update the `run()` function in `src/main.rs` to pass an `OutputFormat` enum (Human | Json) to each `cmd_*` function. When `--json` is set, each command wraps its output in the JSON-RPC 2.0 envelope from task 030.001-T before printing. Exit codes remain unchanged — the envelope carries the result/error, and the process exit code stays consistent.

Note: The `status` subcommand already has a `--json` flag on its own `StatusArgs` struct. That existing flag should be preserved for backward compatibility but should also respect the global `--json` when set.

Acceptance criteria:
- `Cli.json: bool` global flag added
- `OutputFormat` enum (Human | Json) created
- `run()` passes format to all `cmd_*` functions
- Existing human-readable output unchanged when `--json` is absent
- `--help` shows the new global flag
- Unit test confirming the flag parses correctly
