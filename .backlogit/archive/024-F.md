title: PDFium dual backend for large PDF ingestion
updated_at: 2026-05-03T23:30:18.3175707-07:00
---

Add pdfium-render as an optional dual backend for PDF files ≥20 MiB, solving the >20 minute DNF for 104 MB PDFs caused by lopdf's eager xref parsing. PDFium uses lazy document opening (O(1) regardless of file size). The DLL is an optional runtime enhancement — without it, the system degrades gracefully to pdf-extract. Implements dual-backend routing in parse_pdf_document() with PdfiumBackend, PdfiumBindError, and three-tier DLL discovery.
