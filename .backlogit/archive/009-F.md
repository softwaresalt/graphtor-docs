Async MCP server using rmcp crate with tokio runtime over STDIO JSON-RPC transport. Exposes two core tools: search_local_docs (text keyword search via CozoDB search_by_text; HNSW vector search is planned but not yet implemented) and traverse_doc_links (BFS graph traversal via CozoDB find_related_chunks following doc_edges). Localhost-only binding, structured markdown responses. Note: the database layer is unified CozoDB, not separate LanceDB/Kùzu stores.
