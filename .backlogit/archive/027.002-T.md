## Description

The uniform-font fallback in `parse_pdf_document` calls
`extract_text_from_mem_by_pages(bytes)` which internally re-parses the PDF
from raw bytes even though the document was already loaded and scanned in the
histogram pass. For large uniform-font PDFs this duplicates the most expensive
part of the pipeline.

## Acceptance Criteria

- Implement a custom `PerPageOutput` struct implementing `OutputDev` that
  collects text per-page into `Vec<String>` (equivalent output to
  `extract_text_from_mem_by_pages`)
- Pass `&doc` (already loaded) to a second `output_doc` call using
  `PerPageOutput` instead of re-parsing from bytes
- Verify the output matches the existing `extract_text_from_mem_by_pages`
  output for the same PDF bytes (add a round-trip test)
- All existing quality gates must continue to pass

## Notes

Deferred from PR #22 code review (Copilot review comment).
