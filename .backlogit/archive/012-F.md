CozoDB embedded database integration replacing both LanceDB (vector) and Kùzu (graph) with a single unified store. CozoDB provides relational queries (Datalog), property graph traversal, and HNSW vector search in one embedded engine with Rust bindings. Implements: database lifecycle management, Datalog schema definition (node/relation types for SourceRepo, Document, Chunk, CodeSnippet), chunk storage with 384-dim vector embeddings, vector ANN search with repo-scoped filtering, graph edge CRUD (BELONGS_TO, CONTAINS_CHUNK, HAS_CODE, REFERENCES), multi-hop traversal queries, and cross-concern correlation via stable chunk_id keys.
