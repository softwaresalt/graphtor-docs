Add a workspace auto-discovery mode: when no sources.yaml exists (or a special `local: true` entry is present), graphtor detects and indexes all .md/.markdown files in the current repo. Uses git ls-files or filesystem walk with .gitignore respect. Creates an implicit source entry for the local workspace. Enables zero-config adoption: just `graphtor-docs install` + `graphtor-docs sync`.
