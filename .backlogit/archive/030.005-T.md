Update `cmd_init`, `cmd_install`, `cmd_doctor`, `cmd_upgrade`, and `cmd_uninstall` to produce JSON-RPC 2.0 envelopes when the global `--json` flag is set.

Result structures:
- `init`: `{ created: bool, path: string }`
- `install`: `{ created: bool, workspace_dir: string, editors: [...] }`
- `doctor`: `{ checks: [{ name, status: "pass"|"warn"|"fail", detail }], overall: "healthy"|"degraded"|"unhealthy" }`
- `upgrade`: `{ upgraded: bool, from_version: string, to_version: string }`
- `uninstall`: `{ removed: bool, path: string }`

Error cases produce JSON-RPC error envelopes with code -32000 and the error message.

Acceptance criteria:
- All 5 workspace commands produce JSON-RPC 2.0 envelopes when --json is set
- Human-readable output unchanged without --json
- Unit tests for each command's JSON envelope
- Doctor command's check results are fully structured (not just stringified text)
