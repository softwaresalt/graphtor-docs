P1-RF1 (Source-variant compatibility pre-refactor 1 of 5). Add variant-safe accessor(s) to the `Source` enum so no EXTERNAL consumer destructures `Source::Local` irrefutably — unblocking the additive `type: database` variant (P1-T6 / 050.006-T) WITHOUT breaking compilation. Declare `Source::as_local(&self) -> Option<&LocalSource>` as `pub` and add `Source::is_ingestible(&self) -> bool` in src/config/source.rs, AND widen the existing `Source::id()` accessor (src/config/source.rs:60) from `pub(crate)` to `pub`, so the bin crate (src/main.rs, P1-RF4 / 050.013-T) and external integration tests (P1-RF5 / 050.014-T) — SEPARATE crates from the library — can call `Source::id()` / `Source::as_local()` across the crate boundary; `Source::is_ingestible()` MAY remain `pub(crate)` because it is only called inside the library (RF3 / 050.012-T src/sync/mod.rs). Today (only `Local` exists) `as_local` always returns `Some` and `is_ingestible` always returns `true`, so behaviour is identical and this task is independently green. Refactor the three irrefutable `let Source::Local(...)` bindings in src/config/validation.rs (`validate` ~L67, `detect_with_context` ~L210, `intake_key` ~L302) to route through `as_local()` / existing accessors, skipping non-local sources for local-only validation by design. Also route the three colocated `#[cfg(test)]` bindings in src/config/source.rs (`local_source_deserializes_all_fields` ~L162, `formats_defaults_to_md_when_absent_from_yaml` ~L188, `formats_parsed_from_yaml` ~L197) through `as_local()` so the enum's own unit tests stay green when the variant lands. NO new variant is added here (that is P1-T6). Files: src/config/source.rs, src/config/validation.rs (2 files). Depends on 050.001-T (P1-T3). Test-first.

<!-- BEGIN:acceptance-criteria -->
`Source::as_local()` returns `Some(local)` for a `Local` source and `is_ingestible()` returns true; both compile clean under `-D warnings -D clippy::pedantic` (single-arm match; refutable `Option` let-else — no irrefutable-pattern lint).
`validate()` over a local-only `sources.yaml` yields identical errors/success after the refactor.
`detect_with_context()` over a local-only config produces an identical multi-db plan, and `intake_key()` produces identical duplicate-intake keys, after the refactor.
The three colocated `#[cfg(test)]` bindings in src/config/source.rs (~L162/L188/L197) are routed through `as_local()` and stay green; existing config tests stay green; NO `Source::Database` variant exists yet (this task is independently green).
`Source::as_local()` and `Source::id()` are declared `pub` (id widened from `pub(crate)`), so cross-crate visibility compiles: the bin crate (src/main.rs) and external integration tests (tests/*) build clean when they call `id()` / `as_local()` across the library boundary, while `is_ingestible()` remaining `pub(crate)` still compiles for its library-only callers.

<!-- BEGIN:implementation-notes -->
The accessors are the single choke point every consumer uses instead of irrefutable `let Source::Local(...)` destructuring, so once every production and test consumer is routed through them by P1-RF1..P1-RF5, adding `Database(DatabaseSource)` in 050.006-T (P1-T6) only extends source.rs match arms (as_local -> None, is_ingestible -> false, id -> the required `DatabaseSource.id` alias, formats/include/exclude -> empty, database -> `None` [local-target-only; `database()` must NOT return the served path because it feeds the ingestion/generation write path], plus a distinct `served_db_path` accessor -> `Some(DatabaseSource.path)` for the read-only served path) and NO source or test file outside source.rs breaks compilation.
`validate()` (src/config/validation.rs ~L67): replace `let Source::Local(l) = source;` with `if let Some(l) = source.as_local()` gating local-only glob/format checks; the db-name check already routes through `source.database()`.
`detect_with_context()` (~L210): replace `let Source::Local(local_src) = source;` with `let Some(local_src) = source.as_local() else { continue; };` — a served db is not an ingestion source.
`intake_key()` (~L302): replace `let Source::Local(l) = source;` with an `as_local()`-gated key — a served db has no ingestion path to key for duplicate-intake detection (non-local yields no intake key).
The three colocated `#[cfg(test)]` bindings in src/config/source.rs (`local_source_deserializes_all_fields` ~L162, `formats_defaults_to_md_when_absent_from_yaml` ~L188, `formats_parsed_from_yaml` ~L197) are the only breaking consumers in this file's test module; route them through `as_local()` so the enum's own unit tests compile once the variant lands (the `source_database_accessor_returns_none_when_absent` CONSTRUCTOR test ~L203 is non-breaking and untouched).
While only `Local` exists, `as_local()` is always `Some`, so behaviour is unchanged. Pure structural refactor; gates P1-T6 (050.006-T). Executed by Ship; Stage plans only.
