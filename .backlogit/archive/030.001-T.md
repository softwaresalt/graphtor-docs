Create `src/cli/jsonrpc.rs` module with types and helpers for wrapping CLI output in JSON-RPC 2.0 response envelopes. Types needed: `JsonRpcResponse { jsonrpc: "2.0", id: Option<Value>, result: Value }` and `JsonRpcError { jsonrpc: "2.0", id: Option<Value>, error: { code, message, data } }`. Add a `wrap_success(result: impl Serialize) -> String` helper and a `wrap_error(code, message, data) -> String` helper. The `id` field should default to `null` for CLI invocations (no request ID). These types must match the JSON-RPC 2.0 spec and be structurally identical to what rmcp returns over STDIO.

Acceptance criteria:
- `JsonRpcResponse` and `JsonRpcError` structs with serde derive
- `wrap_success` and `wrap_error` produce valid JSON-RPC 2.0 output
- Unit tests confirming envelope structure matches spec
- Module exported from `src/cli/mod.rs`
