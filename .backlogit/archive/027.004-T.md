## Description

Add a regression test that confirms a synthetic large-page PDF (previously forced into page-based chunking by LARGE_PDF_THRESHOLD) now produces section-based chunks with real heading_hierarchy values instead of ["Page N"] placeholders.

## Acceptance Criteria

- Test creates or uses a synthetic PDF with multiple font sizes (simulating headings)
- Test verifies that `parse_pdf_document` returns chunks with section-based heading_hierarchy, not page-number placeholders
- Test explicitly validates that the old LARGE_PDF_THRESHOLD behavior no longer applies
- Test passes in CI without conditional skips

## Notes

This is distinct from 027.001-T (real-PDF integration test). This test validates the threshold removal specifically; 027.001-T validates heading detection accuracy with real content.
